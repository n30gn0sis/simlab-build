# GNS3 server, virtual mirror feed, and reference scenario — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship two tested scripts (`r770-gns3-deploy.sh`, `r770-gns3-scenario-reference.sh`) that deploy GNS3 behind the portal, build the `br-lab` virtual mirror feed into Malcolm, and prove one reference GNS3 topology's traffic actually reaches Malcolm's capture — then run the whole thing end-to-end, offline, on staging VM 9771 (no physical R770 is available).

**Architecture:** Two new scripts follow this repo's `plan | apply | verify` convention (`scripts/r770-lab-ca.sh` is the closest precedent — read it before starting). `r770-gns3-deploy.sh` owns the GNS3 server install/config and, under its `labnet` subcommand, the OS-level bridge/veth mirror plus a pure config-patch helper for Malcolm. `r770-gns3-scenario-reference.sh` owns the one reference topology, its traffic driver, and validation against Malcolm's Arkime/Zeek data. No existing script's code changes.

**Tech Stack:** bash, bats, shellcheck, the GNS3 v3 REST API (curl), iproute2 (`ip link`), Docker CLI (GNS3 docker nodes are real containers), python3 (JSON patching).

**Spec:** `docs/superpowers/specs/2026-09-27-gns3-mirror-design.md`

## Global Constraints

- Shellcheck-clean, **no `# shellcheck disable` directives** (repo convention; enforced by `tests/lint.bats`).
- **No secrets in the repo, a log, argv, or a subagent prompt.** GNS3's admin password/JWT are generated on the box, never committed — same pattern as `r770-lab-ca.sh` and Malcolm `auth`.
- `git add` the changed files **before** `./tests/run.sh` (the owners guard only scans tracked files — session memory).
- **Chain gates with `&&`, never `;`** (session memory): tests → commit, apply → verify, stage → launch.
- Bridge/veth/interface names here (`br-lab`, `lab-mon0`, `lab-mirror0`) are fixed constants set by the design, not discovered — but every script still probes live state (`ip link show`) before acting, never assumes it.
- **Simple before clever:** a hub-mode Linux bridge, never OVS (buildout §7.2; repo decision rules).
- **Capture ports and the management NIC are never touched** by anything in this plan — `br-lab`/`lab-mon0`/`lab-mirror0` are lab-internal virtual interfaces only.
- **Staging only.** Everything here runs on VM 9771 via `scripts/r770-staging-vm.sh`'s Proxmox token (scoped to `/vms/9770` and `/vms/9771` only); the real R770 is out of scope for execution in this plan (design only — see spec's "R770 afterwards").
- This plan only **consumes** what the bundle already stages (`gns3-server` wheelhouse, `netshoot`/`alpine`/`debian` docker images, the `alpine-linux.gns3a` appliance definition) — no new fetch-script pins.
- Commits end with the attribution lines from the session's system reminder.

## Review Focus

- `labnet apply` run twice must be a no-op, not a duplicate-interface error — every sibling script in this repo is idempotent by convention.
- `r770-gns3-deploy.sh apply` finding a previously-started, incomplete venv (an interrupted install) must refuse clearly, not silently treat it as done or corrupt it further.
- `labnet malcolm-config` must refuse, not silently patch, a source JSON it can't parse — a bad Malcolm config that then makes `install.py` choke is worse than refusing early.
- `r770-gns3-scenario-reference.sh run` must refuse if the GNS3 nodes aren't actually in a started state, rather than writing an evidence file claiming traffic was sent when it wasn't (CLAUDE.md rule 4: never fabricate results).
- `r770-gns3-scenario-reference.sh verify` must poll with a bounded timeout for Arkime/Zeek to ingest recent traffic (a real race — capture lags slightly behind the wire), not FAIL on a simple timing race, but must still FAIL (not hang) once the timeout is exceeded — mirrors Malcolm's own `health` verb.

ensure_venv() {
    case "$(venv_state)" in
        ready) echo "KEEP    venv already has gns3server ($GNS3_VENV)"; return 0 ;;
        broken) die "$GNS3_VENV exists but has no bin/gns3server -- looks broken, not a usable venv. Remove it manually if that's intended, then re-run apply." ;;
    esac
    wheel_present || die "no gns3-server wheel in $GNS3_WHEELHOUSE -- is the bundle's gns3/ staged?"
    echo "CREATE  venv at $GNS3_VENV"
    python3 -m venv "$GNS3_VENV" || die "python3 -m venv $GNS3_VENV failed"
    "$GNS3_VENV/bin/pip" install --no-index --find-links "$GNS3_WHEELHOUSE" gns3-server ||
        die "pip install gns3-server from $GNS3_WHEELHOUSE failed (venv left at $GNS3_VENV for inspection)"
    [ -x "$GNS3_VENV/bin/gns3server" ] || die "pip reported success but $GNS3_VENV/bin/gns3server is missing"
}

ensure_conf() {
    if [ -f "$GNS3_CONF_DIR/gns3_server.conf" ]; then
        echo "KEEP    $GNS3_CONF_DIR/gns3_server.conf already installed (password/JWT never regenerated)"
        return 0
    fi
    local pass jwt tmp
    pass=$(openssl rand -base64 24) || die "openssl rand (password) failed"
    jwt=$(openssl rand -hex 32) || die "openssl rand (jwt) failed"
    mkdir -p "$GNS3_CONF_DIR" || die "could not create $GNS3_CONF_DIR"
    tmp="$GNS3_CONF_DIR/.gns3_server.conf.tmp.$$"
    sed -e "s#__PASSWORD__#$pass#" -e "s#__JWT__#$jwt#" "$GNS3_CONF_TEMPLATE" > "$tmp" ||
        die "could not render $GNS3_CONF_TEMPLATE"
    install -m 0640 "$tmp" "$GNS3_CONF_DIR/gns3_server.conf" || die "could not install gns3_server.conf"
    rm -f "$tmp"
    echo "INSTALL $GNS3_CONF_DIR/gns3_server.conf (password/JWT generated on this box, never logged)"
}

ensure_user() {
    getent passwd "$GNS3_USER" >/dev/null 2>&1 || {
        useradd --system --create-home --shell /usr/sbin/nologin "$GNS3_USER" || die "useradd $GNS3_USER failed"
    }
    usermod -aG kvm,docker "$GNS3_USER" || die "usermod -aG kvm,docker $GNS3_USER failed"
}

ensure_dirs() {
    local d
    for d in "$GNS3_PROJECTS_DIR" "$GNS3_IMAGES_DIR" "$GNS3_APPLIANCES_DIR"; do
        mkdir -p "$d" || die "could not create $d"
        chown "$GNS3_USER:$GNS3_USER" "$d" || die "could not chown $d"
    done
}

ensure_service() {
    local unit="/etc/systemd/system/gns3.service"
    sed -e "s#__GNS3_USER__#$GNS3_USER#" -e "s#__GNS3_VENV__#$GNS3_VENV#" -e "s#__GNS3_CONF_DIR__#$GNS3_CONF_DIR#" \
        "$GNS3_SERVICE_TEMPLATE" > "$unit.tmp.$$" || die "could not render $GNS3_SERVICE_TEMPLATE"
    if [ -f "$unit" ] && cmp -s "$unit.tmp.$$" "$unit"; then
        rm -f "$unit.tmp.$$"
    else
        mv -f "$unit.tmp.$$" "$unit" || die "could not install $unit"
        systemctl daemon-reload || die "systemctl daemon-reload failed"
    fi
    systemctl enable --now gns3 || die "systemctl enable --now gns3 failed"
}

ensure_nginx_vhost() {
    mkdir -p "$GNS3_NGINX_DIR/conf.d" || die "could not create $GNS3_NGINX_DIR/conf.d"
    local dest="$GNS3_NGINX_DIR/conf.d/gns3.lab.conf"
    if [ -f "$dest" ] && cmp -s "$GNS3_NGINX_VHOST" "$dest"; then
        echo "SKIP    $dest already installed"
    else
        install -m 0644 "$GNS3_NGINX_VHOST" "$dest" || die "could not install $dest"
        systemctl reload nginx 2>/dev/null || echo "NOTE    nginx reload skipped or failed -- reload it once nginx is managed (r770-portal.sh apply)"
    fi
}

cmd_apply() {
    require_root
    [ $# -eq 0 ] || die "unknown argument: $1"
    ensure_venv
    ensure_conf
    ensure_user
    ensure_dirs
    ensure_service
    ensure_nginx_vhost
    echo "PASS    gns3-server applied ($GNS3_VENV, user $GNS3_USER, service gns3.service)"
}
